---
name: Personal reminder scope
description: The user's chosen scope for custom reminder messages sent by the Smart Money Hub bot.
---

Only the configured CEO/admin can create personal reminders. Those reminders are one-time only; do not add recurring personal reminders unless the user asks for them.

**Why:** The user chose one-time reminders and clarified that this feature should benefit only them.

**How to apply:** Verify the existing configured admin ID before accepting or delivering personal reminders. Keep parsing and scheduling single-occurrence; do not infer recurring schedules from repeated wording.

---
name: Market Analysis editorial style
description: The user's requirements for fresh, channel-aware Smart Money Hub Market Analysis posts.
---

Generate a fresh post for every scheduled Market Analysis slot. Use recent channel history to match current channel context and vary topic and layout; do not repeat the same lesson in slightly different wording. The user likes an ambitious, energetic, conversational lifestyle tone, but claims about profits, winning trades, or weekly performance must be supported by verified information.

For promotions, do not rely on Gemini retries alone to remove copy about features belonging to another destination. Remove only the out-of-scope sentence, then rerun the complete existing validation chain; never relax a publishing check.

**Why:** the user wants Gemini-generated posts to reflect the channel's current context, and Gemini repeated an excluded feature phrase despite its absence from the prompt; unsupported claims mislead members, while deterministic sentence removal preserves useful copy without weakening checks.

**How to apply:** when selecting a topic, tone, or structure for any Market Analysis post, consider recent published posts and timing. Use energetic language without fabricating market events or trading results; avoid treating a wording change alone as sufficient novelty. If promotional copy refers to a feature at another destination, remove that sentence and rerun all checks before saving or publishing.

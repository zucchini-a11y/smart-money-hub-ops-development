---
name: Education topic promotion publishing
description: Owner-approved publishing and recovery rules for Monday/Thursday Education-group promotions.
---

Scheduled Monday/Thursday Education-group promotions should publish automatically at their scheduled WAT time without waiting for admin approval, provided generation, content validation, destination verification, and Telegram delivery checks pass. A private preview is useful for optional edits or a photo, but it is not an approval gate.

Promotions prepared on a Monday or Thursday should also advertise the free Zoom class at 8:00 PM WAT. Keep that notice secondary to the Market Analysis channel promotion and say the class link is shared in the main Smart Money Hub channel when class begins.

**Why:** the owner explicitly asked for these scheduled promotions to post on time without approval and pointed out that the 8:00 PM class must be advertised in the promotion.

**How to apply:** preserve automatic publishing for eligible drafts. On Monday/Thursday, include the required class reminder in both scheduled and manually requested promotions. If the scheduler misses the preview tick, recover only within the configured on-time grace window; after it expires, hold the promotion rather than posting late. Keep cancellation, incomplete edits, failed checks, and destination changes as blockers.

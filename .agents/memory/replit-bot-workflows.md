name: Replit bot workflow scope
description: The user's instruction for stopping noisy Replit bot workflows and distinguishing them from VPS services.
---

Keep Replit Smart Money Hub bot and WhatsApp bot workflows stopped unless the user explicitly asks to start them. Replit workspace edits and workflow state do not automatically alter the separately deployed Hostinger VPS.

**Why:** the user asked to stop the Replit bots because their messages were disturbing and expected changes made in Replit to be distinguished from VPS production changes.

**How to apply:** when asked to stop Replit bots, stop their managed Replit workflows and state clearly that any VPS-hosted bot remains separate and requires its own authorized service action.
